# FrontierEval

**Do the AI plugins your team relies on get worse as the models get better?**

FrontierEval is a small, repeatable test of that question. Its first subject is Anthropic's official code-review plugin for Claude Code, compared against a plain review prompt on real pull requests, across two current models.

**Status (15 November 2026): pilot in preparation.** The method is built and proven on real runs. The scored pilot has not run yet.
